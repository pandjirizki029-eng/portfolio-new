# 📁 Folder Foto

Taruh foto kamu di sini dengan nama:

**`profile.jpg`** (atau `profile.png`)

Contoh path lengkap:
`d:\porto\public\images\profile.jpg`

Foto akan otomatis muncul di Hero (halaman utama).

> Tips: Gunakan foto vertikal (portrait) dengan background gelap atau transparan agar hasilnya maksimal.
